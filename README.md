# 🎬 MovieExplorer — Assignment 2

A responsive Movie Explorer application built with **React, Vite, and Tailwind CSS**. Users can browse shows, search by title, and view detailed information in an interactive modal.

## 🌐 Live Demo

https://classy-marigold-f263d5.netlify.app/

## 🔗 GitHub

https://github.com/sanimmahbub456-creator/movie-explorer-Assignment2

## ✨ Features

* 🎬 Responsive Navbar
* 🎥 Movie-related Hero Banner
* 🔍 Search shows by title
* 🖼️ Responsive movie/show cards
* ⭐ Rating and release date
* 🎞️ Interactive Details Modal
* 📱 Fully responsive design
* 📄 Footer with copyright
* 🌐 TVMaze API integration

## 🛠️ Technologies

* React.js
* Vite
* JavaScript
* Tailwind CSS
* React Router
* TVMaze API

## 🌐 API

TVMaze API:
https://www.tvmaze.com/api

### Endpoints

```text
GET https://api.tvmaze.com/shows
GET https://api.tvmaze.com/search/shows?q=:query
```

## 🚀 Run Locally

```bash
git clone https://github.com/sanimmahbub456-creator/movie-explorer-Assignment2.git
cd movie-explorer-Assignment2
npm install
npm run dev
```

Deployed with **Netlify**.
